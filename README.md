# 🔐 Password Security Checker

A desktop application built using C++ and Qt that analyzes password strength based on length, character composition, common-password detection, repeated characters, and estimated entropy.

The application also provides security recommendations and includes a random password generator.

## 🚀 Features

- 🔍 Password strength analysis
- 📏 Password length checking
- 🔠 Uppercase and lowercase character detection
- 🔢 Digit detection
- 🔣 Special character detection
- ⚠️ Common password detection
- 🔁 Repeated character detection
- 📊 Password strength scoring
- 💡 Security suggestions
- 🧮 Entropy calculation
- 📈 Entropy-based strength analysis
- 🔑 Random password generator
- 👁️ Show/Hide password functionality

## 🛠️ Technologies Used

- C++ — Core programming and password analysis logic
- Qt 6 — Graphical User Interface (GUI)
- CMake — Project configuration and build system

## ▶️ How to Run

### Prerequisites

- Qt 6
- CMake
- C++ compiler
  
1.)Clone the repository.
2.)Open the project in Qt Creator.
3.)Configure the project using Qt 6.
4.)Build the project.
5.)Run the application.
- C++ compiler (MinGW or MSVC)
